# Raw artefact Pull
> ! Prototype, not tested in production
> [Original Source](https://gitlab.com/piersharding/ansible-raw-artefacts/-/tree/master/roles/raw_artefact_pull?ref_type=heads) 

This role is used to pull/download raw artifacts from BAR/CAR onto servers. This role is required in the provisioning process to provide FHSs access to various code, packages, and bitstreams.
